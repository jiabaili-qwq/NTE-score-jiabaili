# jiabaili 评分包（NTEUID / 异环）

> [NTEUID](https://github.com/tyql688/NTEUID) 的外置评分包（scoring package），`scorer_id`: `jiabaili`。
> 适配 NTEUID 的 [scoring 评分体系](https://github.com/tyql688/NTEUID/tree/main/NTEUID/scoring)。
>
> **角色权重数据来源小程序：异环工坊**

适用游戏：异环 / Neverness to Everness（NTE）。安装方式见下文「安装」。

## 计算标准

整套满分 **350**（空幕 35 格 × 10 分）：

- 核心件（卡带）：`(主词条权重 × 50 + 副词条权重 / 理论满权重 × 100) × 品质`
- 盘件（驱动块）：`(副词条权重 / 理论满权重 × 面积 × 10) × 品质`
- 理论满权重 = 该角色副词条权重最高的 4 个之和
- 品质系数：橙 1.0 / 紫 0.8 / 其余 0.6
- 驱动块面积：装备 id `cellN_*` 的 N（占格数）

## 词条高亮

- **主词条**：权重最高的属性高亮（并列都亮）
- **副词条**：权重最高的前 4 个属性高亮（与理论满权重口径一致）
- **角色属性面板**：与装备词条同一口径高亮；属性 id 与权重表不同名时，按
  `attributes.json` 的名称反查判定（id 精确命中优先，name 反查兜底）
- 高亮颜色为**金色**（已解锁 `RGB(255,200,64)`，未解锁副词条用暗金 `RGB(180,150,50)`）
- 核心件（卡带）与盘件（驱动块）**均不挂**评级徽章
- 评分时若**主词条数据缺失**（服务端只回 `id` 缺 `name`/`value`），默认按
  「魂属性异能伤害增强」（`damageuppsychebase`）取主词条权重

## 总评分评级

按总分（350 满分）固定分档：

| 评级 | 分数线 |
| --- | --- |
| ACE | ≥ 280 |
| SSS | ≥ 260 |
| SS  | ≥ 240 |
| S   | ≥ 220 |
| A+  | ≥ 200 |
| A   | ≥ 180 |
| B   | ≥ 160 |
| C   | ≥ 140 |
| D   | < 140 |

## 权重数据策略

本包**不预置任何权重数据**：

1. 首次成功请求异环工坊接口后，自动把权重缓存到本地 `data/weights_cache.json`。
2. 后台任务**每天 00:00 / 06:00 / 12:00 / 18:00** 四个整点请求接口并刷新该缓存文件。
3. 每次评分优先**实时请求接口**获取最新权重；接口请求失败时，自动**降级**到
   `data/weights_cache.json` 做计算。
4. 接口不可用且本地尚无缓存（首次部署未拉取过）时，评分返回「评分数据缺失」，
   待接口恢复即自动建立缓存，无需手工放置任何权重文件。

使用时请标注：**权重配置来自：异环工坊**。

## 使用

1. 把本目录（`NTE-score-jiabaili/`）放到 `NTEUID/scoring/scorers/` 中（或 `ntescorer增加 <仓库地址>` 安装）
2. 重启 Bot 后发送 `ntescorer设置 jiabaili` 切换评分算法
3. 发送 `nte刷新面板` 按新算法重新计算

## 文件结构

```
NTE-score-jiabaili/
├── __init__.py      # 评分器实现（导入即注册）
├── assets/          # 评级徽章素材（rank_D ~ rank_ACE）
├── data/            # 交付时为空；运行时自动生成 weights_cache.json
└── README.md
```

> `data/weights_cache.json` 为运行时生成的权重缓存（异环工坊接口快照），
> 由首次接口成功 + 每天 00:00 / 06:00 / 12:00 / 18:00 定时刷新维护，请勿手工编辑。
